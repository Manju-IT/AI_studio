# Phase 11.5: local launcher
Stop existing services first. Keep PostgreSQL running. From the project root run `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Check`, then `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1`. Alternatively use `.venv\Scripts\python.exe scripts/run_local.py`. Add `--no-browser` to Python or `-NoBrowser` to PowerShell.

Logs are under configured storage_root/logs, in a timestamped directory. Ctrl+C requests group shutdown. Avoid closing the terminal abruptly. Windows CTRL_BREAK and taskkill fallback are best effort; verify no leftover worker or child processes before restarting or maintenance. In-flight jobs may fail and need retry. PostgreSQL is not started/stopped, migrations are not applied, and no packages or models are installed. The launcher uses fixed local ports 8000 and 3000 matching existing frontend defaults. Backend runs without reload; frontend uses Next dev. Health checks do not establish model readiness or schema compatibility. Worker heartbeat warnings are advisory. Logs are not automatically rotated or deleted. The launcher does not prevent manually starting services outside it. Keep logs private.
