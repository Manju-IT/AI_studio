# Private Qwen cloning integration
Stop backend and supervisor before replacing files. No migration. Start backend and frontend only. Do not run ASR, diarization or model benchmarks during extraction. Set QWEN_HF_MODEL_PATH to the existing HF snapshot if offline cache resolution fails. Open Voice Cloning, select Qwen, supply consent, 3–15 second reference and exact transcript. Extract runs in a child process with a 15-minute timeout; keep page open. Existing pending profiles with references can be retried. Restart supervisor after extraction, then select the ready voice in Studio. Assets live in storage/private_voices/<voice UUID>, not the global model directory. Back up that directory with database and reference files. The extraction request is synchronous, not a durable queue. Worker lock requires supervisor to be stopped. No ASR coordination yet. Qwen cold admission is 10 GiB; extraction admission 8 GiB (provisional). No guarantee of memory safety. Existing manual voice_test is not automatically imported. Windows runtime, DB and frontend integration tests pending.
